# MineGPT — نمونهٔ اولیهٔ Forge 1.12.2

این فایل یک **پروژهٔ منبع اولیه** است، نه فایل مود `.jar` آماده و کامپایل‌شده.

## قابلیت‌های همین نمونه
- مود برای Minecraft 1.12.2 / Forge 14.23.5.2860
- دستور `/minegpt spawn` برای ظاهر کردن یک همراه humanoid با نام MineGPT
- حرکت آزاد ساده و دنبال‌کردن بازیکن نزدیک
- واکنش رزمی پایه به ماب‌های خصمانه
- دستور `/minegpt status` برای نمایش وضعیت نمونه
- طراحی آفلاین؛ مدل زبانی یا API لازم ندارد

## قابلیت‌هایی که هنوز پیاده‌سازی نشده‌اند
- جمع‌کردن چوب، ساخت ابزار یا خانه
- یادگیری واقعی با آزمون‌وخطا یا یادگیری از رفتار بازیکن
- ذخیرهٔ تجربه‌ها و مهارت‌ها
- چت فینگلیش
- درخواست اجازهٔ تقلب با y/n
- PvP یادگیرنده

این‌ها مراحل بعدی پروژه‌اند؛ این نمونه فعلاً ادعای انجامشان را ندارد.

## ساخت
این پروژه برای محیط توسعهٔ ForgeGradle قدیمی ساخته شده است. طبق مستندات Forge 1.12.x، توسعه با JDK 8 و MDK همان نسخه در نظر گرفته شده است. در یک محیط توسعهٔ سازگار، محتویات را باز کنید و از Gradle task `build` استفاده کنید. اولین بار ممکن است برای دریافت وابستگی‌های Gradle به اینترنت نیاز باشد؛ خود مود در بازی برای قابلیت‌های فعلی به اینترنت/API نیاز ندارد.

پس از ساخت موفق، فایل jar در `build/libs/` قرار می‌گیرد. آن را در پوشهٔ `mods` پروفایل Forge 1.12.2 قرار دهید.

## احتیاط
این پروژه در این محیط کامپایل یا داخل PojavLauncher آزمایش نشده است. Forge 1.12.2 قدیمی است و ممکن است برای ساخت به اصلاحات محیطی نیاز داشته باشد. قبل از استفاده از دنیای اصلی، از دنیا نسخهٔ پشتیبان بگیرید.
